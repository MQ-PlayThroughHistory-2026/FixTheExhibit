# Project Proposal for "Fix the Exhibit"

**we can update as project progresses & scope is clarified, this is just to initialise the project -YS**

An interactive browser-based sorting game designed to evaluate video game accuracy against real museum artifacts. The core goal is to engage users in identifying historical misconceptions and pop-culture tropes while true showcasing digitised collections.

## Core experience:
Players take on the role of a museum curator racing against the clock to correct scrambled displays. A conveyor belt feeds items across the screen, mixing real with fake (e.g., a 19th-century miner’s cradle alongside a Minecraft diamond sword or Fortnite weapon). Players drag genuine objects into the display case while tossing pop-culture myths into a rejection bin. Sorting an item gives instant micro-feedback explaining the real history. Level completion rewards/achievement to be determined, potentially just a score to go on a leaderboard or a printable version of one of the correctly sorted artifacts.

## Scope:
- A number of different levels depending on difficultly, or number of exhibits in  the actual museum, covering more general but distinct historical themes/eras (e.g., Mesozoic Era, 1850s Gold Rush, Ancient Egypt), or using the museums resources.

- Drag-and-drop / swipe mechanics with timer and scoring system.

- Pre- and post-game mini-quizzes to measure player learning for research data.

- Web application so it can be universally suported with desktop or mobile touch support.
